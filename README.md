Chào mừng bạn đến với repo mã nguồn website Portfolio 3D cá nhân của **Lê Tuấn Kiệt**.

Website được thiết kế theo phong cách không gian số (Cybernetic / Quantum Universe), trực quan hóa kiến trúc hệ thống Backend thành các khối tương tác 3D sinh động, kết hợp giữa tư duy kỹ thuật nền tảng vững chắc và giao diện hiện đại, mượt mà.

## 🛠️ Công Nghệ Sử Dụng (Tech Stack)

### Frontend & 3D Engine
- **React 18** & **TypeScript**
- **Three.js** / **@react-three/fiber** / **@react-three/drei**
- **@react-three/postprocessing** (Bloom & Glow Shaders)
- **Tailwind CSS** (Kiến trúc giao diện & Dark theme)
- **Framer Motion** & **GSAP** (Hiệu ứng chuyển động)
- **Lenis** (Smooth scroll cuộn mượt mà)
- **Lucide React** (Bộ biểu tượng hiện đại)

### Nền Tảng Backend & Kỹ Năng Chuyên Môn
- **Ngôn ngữ**: Java (Core, OOP, Multithreading), TypeScript, JavaScript, C
- **Framework & Công nghệ**: Spring Boot, RESTful APIs, Spring Security & JWT, Redis (Caching)
- **Cơ sở dữ liệu**: MySQL, MongoDB, SQL Server
- **DevOps & Công cụ**: Docker, Git/GitHub, Postman, JMeter (Load test), Mockito (Unit test), PMD (Static analysis)
- **Triển khai**: Vercel, Render, Railway

## 💻 Cài Đặt & Chạy Cục Bộ (Getting Started)

### Yêu cầu tiên quyết
- **Node.js**: v18.0 trở lên
- **npm** hoặc **yarn** / **pnpm**

### Các bước cài đặt

```bash
# 1. Clone repository
git clone https://github.com/letuankiet-04/kietlee-portfolio.git

# 2. Điều hướng vào thư mục dự án
cd kietlee-portfolio

# 3. Cài đặt các gói phụ thuộc
npm install

# 4. Khởi động môi trường phát triển cục bộ
npm run dev
```

Truy cập trình duyệt tại: `http://localhost:5173`

### Xây dựng bản Production

```bash
npm run build
```

Kiểm tra bản build:
```bash
npm run preview
```
